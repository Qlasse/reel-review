# Пометки на кадре

`<scripts>` ниже — папка `scripts/` рядом с этим файлом (базовая папка скилла + `/scripts`). Все команды — из корня проекта.

## Как устроен проект

Ролик живёт в папке бренда: `<бренд>/edit/<id>/` — данные (`captions.json`, `visual_plan.json`, `sfx.json`, `reelkit-props.json`, `notes.json`), `<бренд>/out/` — мастера. Бренд — папка с `it-reelsmaker.json` (подпапки корня; если их нет, а файл лежит в корне — бренд один, сам корень). Remotion-проект бренда — `remotion_dir` из того же `it-reelsmaker.json`; композиция ролика `<id>` называется `Reel<Id>` (ab-14 → ReelAb14).

Остальное — в `.reel-review.json` в корне проекта (файла может не быть):

| Ключ | Что | Нет — что будет |
|---|---|---|
| `tracker`, `published` | таблица статусов (Markdown, «## <бренд>», колонки «Ролик … Статус …»), файл отметок публикации | нет списка статусов |
| `check` | скрипт проверки мастера: `python3 <check> <бренд> <id> --master out/<файл>`, строки «ОШИБКА / ПРОВЕРИТЬ / ок …» | нет значка проверки |
| `sfx` | скрипт сведения звуков поверх мастера голоса: `python3 <sfx> <видео> <sfx.json> -o <выход>` | звуки сводит только «Собрать версию» |
| `rules`, `rule_sections` | файлы правил (glob от корня) и раздел, куда дописывать правило | только `CLAUDE.md` |
| `plugin_dirs` | плагины для Claude со страницы (it-reelsmaker из приложения Claude находится сам) | — |
| `port` | порт страницы | 8765 |
| `settings` | то, что меняет окно «Настройки»: модель, effort, права, потолок расходов, размер клипа предпросмотра, добавка к заданию, `idle_minutes` | умолчания |

## Открыть страницу

- `python3 "<scripts>/server.py" --root "<корень проекта>"` → `http://127.0.0.1:8765`. В приложении Claude — конфигурация в `.claude/launch.json` с этой командой и `preview_start`.
- Ссылка сразу на ролик и кадр: `http://127.0.0.1:8765/#<Бренд>/<файл мастера>@<кадр>`.
- Без работы сервер выключается сам: страница закрыта (она опрашивает сервер каждые 4–5 с), а Claude, рендер и проверка не идут — `settings.idle_minutes`, по умолчанию 30; 0 — не выключать. Включить снова — той же командой.
- Сервер держит код в памяти: после правки `.py` его перезапустить; `index.html` и `rules.html` подхватываются перезагрузкой вкладки.
- Пометки ставит только пользователь. Claude на странице ничего не добавляет и не удаляет: он отвечает через `notes.py`.

## Claude со страницы

Кнопки запускают `claude -p` без чата (`jobs.py`) из корня проекта; нужен вход консольного Claude (`claude auth login`, один раз).
- **Внести N пометок**, **Собрать версию** (полный рендер, мастер, звуки, проверка), **Правила из правок · N**, **Выбрать вариант**. Под полем пометки: **Добавить** (⌘Enter), **Сделать** — добавить и сразу отдать Claude (⌘⇧Enter), **3 варианта** — текст поля как задание вариантам (⌘⌥Enter).
- Один ролик — одна сессия: номер в `notes.json` («session»), каждый запуск её продолжает; ↻ в шапке Claude её сбрасывает. Открыть разговор: `claude --resume <номер>`.
- Лента — `edit/<id>/claude-feed.jsonl`. Одна тяжёлая задача за раз: Claude, предпросмотр, проверка, «в мастер».

Если задание пришло со страницы: ход работы пользователь видит в ленте, вопросы задавать через `set <n> question`, а не текстом; полный рендер — только по «Собери версию».

## Внести пометки

1. `python3 "<scripts>/notes.py" "<бренд>" <id> list` — ждущие пометки (`new`, `reopened`): кадр, отрезок, тип, текст, фигуры в координатах 1080×1920, последняя реплика. У возвращённых читать всю ветку (`list --all`).
2. По каждой: `notes.py … frame <n> before` — кадр мастера с отметками в `edit/<id>/notes/<n>-before.png`. Посмотреть его.
3. Найти элемент в коде: время → сегмент и вставка в `visual_plan.json`, слово в `captions.json`, `Sequence` в композиции (кадр мастера = кадр композиции). Координаты фигур — в кадре после камеры.
4. Непонятно или спорит с правилами проекта — не угадывать: `set <n> question "…"` с вариантами ответа.
5. Все правки за один заход. Каждую показать **предпросмотром из кода**: `notes.py … preview <n>` (≈ 5 с; у пометки с отрезком — ещё клип) — прикладывается как «после · из кода». Посмотреть и ответить: `set <n> done "что сделано"`, `wontfix "почему"`.
6. После полного рендера — проверка проекта и `frame <n> after` с мастера (если время сдвинулось — `--frame N`).

Как читать пометку: тип ставит страница — `draw` (эскиз графики), `timing` (отрезок I–O), иначе `other`. Рамка — что менять, стрелка — куда или траектория, точка — место. **Эскиз графики** (`pen`, плашка `rect` с `fill`, `text`; у фигур свой `color`) — замысел, а не макет: место, размер, цвет и слова — с эскиза, шрифт, движение и время на экране — из правил бренда и проекта.

## Три варианта (`variants.py`)

`begin "<задание>" [--frame N] [--range a-b]` → id; для каждого варианта a, b, c: правка → `save <id> <ключ> "чем отличается"` (снимок и предпросмотр) → `base <id>`. В конце код исходный; «Выбрать» на странице возвращает файлы выбранного. Снимок — только файлы ролика (`<remotion>/src/Reel<Id>*.tsx`, `<remotion>/src/plans/<id>*.json`, `edit/<id>/*.json`): общий кит вариантами не править.

## Правила из правок

Принятая пометка или возвращённая (`returned`) — кандидат. `notes.py … rule <n> "<файл>" "<текст>" [--section]` предлагает строку, `rule <n> none "почему"` — правила не будет. Сначала прочитать файл и не дублировать. В файл правил Claude сам не пишет: строку вставляет кнопка «Записать» (`notes.insert_rule`, в конец раздела).

## Дорожки и правки без Claude (`tracks.py`)

Склейки, вставки, слова субтитров, звуки `sfx.json`, находки проверки (⚠ или C).
- **Слово** правится во всех копиях (`captions.json`, `reelkit-props.json`, `<remotion>/src/plans/<id>.json`); «В мастер» перерисовывает ±4 с вокруг слова `patch_render.py` плагина it-reelsmaker прямо в мастере. Субтитры из своего плана композиции — только просмотр.
- **Звук**: время мышью или полем, громкость ±1 дБ; «В мастер» — видео мастера + `out/renders/<id>-voice.mp4` + скрипт `sfx`.
- Прежний мастер — `out/renders/<имя>-prev.mp4`, один, перезаписывается.

## Окно «Правила и настройки», удаление, статус

- `/rules` правит файлы правил; сохранение не затрёт чужую правку (сверка времени изменения).
- Корзина в шапке ролика (⌘⌫): этот мастер или весь ролик (`out/`, `edit/<id>/`, `<remotion>/public/<id>/`, строка в таблице) — в Корзину, код композиции остаётся.
- Статус (если есть `tracker`): «опубликован» спрашивает ссылку, дату и результат и пишет их в таблицу и в файл отметок. Claude статус «опубликован» за пользователя не ставит.

## Осторожно

- Предпросмотр рисует текущий код, а не мастер; звуки и мастер звука в клип не входят.
- В поле `master` записан файл, к которому ставили пометку; после перенарезки искать место по содержанию кадра.
- Статус `accepted` ставит только пользователь.
- Клавиши страницы — по физическим клавишам, работают в любой раскладке; список — «?» на странице.
