# reel-review — пометки на кадре для монтажа Reels с Claude Code

Локальная страница, на которой монтажёр смотрит мастер вертикального ролика, ставит пометки прямо на кадре, а Claude
вносит правки — из чата или сам, по кнопке на странице.

- **Пометки на кадре:** точка, рамка, стрелка, отрезок кадров; эскиз новой графики кистью, плашкой и текстом.
- **Claude без чата:** «Внести пометки», «Сделать», «3 варианта», «Собрать версию». Работает консольный `claude -p`,
  одна сессия на ролик, пока она не разрослась (потом — новая: каждый ход перечитывает весь разговор), ход работы,
  число ходов и размер разговора — лентой на странице.
- **Предпросмотр из кода без рендера:** кадр за ~5 с, отрезок — клипом; страница говорит, отличается ли кадр от мастера.
- **Дорожки под видео:** склейки, вставки, слова субтитров, звуки, находки проверки. Мышью: середина блока — сдвиг,
  край — обрезка (по кадрам). Слова, вставки и звуки уходят в мастер без Claude: картинка — перерисовкой ±4 с вокруг
  правки, звуки — пересведением; обрезка склейки становится пометкой для Claude (перенарезка сдвигает всё после неё).
  Опечатка в слове и громкость звука — там же.
- **Три варианта** одной правки рядом, выбор одним кликом.
- **Правила из правок:** из принятых и возвращённых пометок Claude предлагает строки в правила; записывает пользователь.
- ⌘Z, горячие клавиши («?» на странице), замедление просмотра до 0.1×, удаление в Корзину с подтверждением.

## Что нужно

- macOS (удаление идёт в Корзину через `/usr/bin/trash`), Python 3.10+ с Pillow, ffmpeg и ffprobe, Node.js.
- Проект роликов в раскладке плагина it-reelsmaker (ставится в приложении Claude): папка бренда с `it-reelsmaker.json`,
  `edit/<id>/`, `out/`, Remotion-проект с композициями `Reel<Id>`. Без it-reelsmaker не работают перерисовка
  субтитров в мастере и Claude со скиллом монтажа; пометки, предпросмотр и дорожки работают.
- Для Claude со страницы — консольный `claude` и долгоживущий ключ подписки, один раз:

  ```bash
  claude setup-token
  ```

  Скопируйте ключ целиком — он печатается на двух строках, — и выполните:

  ```bash
  python3 <папка плагина>/skills/reel-notes/scripts/jobs.py key
  ```

  Команда возьмёт ключ из буфера обмена, склеит строки, положит в Связку ключей macOS (служба `reel-review`) и одним
  коротким запуском проверит, что Claude его принимает. Ключ нигде не печатается; плагин передаёт его только
  запускаемому `claude`. Вставлять ключ в запрос `security … -w` вручную не стоит: перенос строки обрывает ввод, и в
  Связке оказывается половина ключа.
  Можно и переменной `CLAUDE_CODE_OAUTH_TOKEN` в окружении сервера. Обычный `claude auth login` тоже работает, но его
  вход может слететь, и тогда Claude со страницы падает с «OAuth session expired».

## Установка

```bash
claude plugin marketplace add Qlasse/reel-review
claude plugin install reel-review@reel-review
```

## Настройка проекта

Файл `.reel-review.json` в корне проекта — необязателен; всё, чего в нём нет, страница прячет сама.

```json
{
  "tracker": "reels.md",
  "published": "published.txt",
  "check": "scripts/check.py",
  "sfx": "scripts/mix_sfx.py",
  "rules": ["CLAUDE.md", "*/brands/*/rules.md"],
  "rule_sections": {"rules.md": "Rules from revisions"},
  "grid": [{"rect": [65, 269, 950, 979], "color": "lime"}],
  "port": 8765
}
```

`grid` — зоны поверх кадра 1080×1920 (кнопка «Сетка», G); в примере — безопасная зона рекламы Reels по справке Meta
(сверху 14 %, снизу 35 %, по бокам 6 %). `check` и `sfx` — свои скрипты проекта, их интерфейс описан в `config.py`.

Ключи подробно — в `plugin/skills/reel-notes/scripts/config.py` и в описании скилла.

## Запуск

В Claude Code: «открой страницу пометок» — скилл `reel-notes` запустит сервер. Вручную:

```bash
python3 <папка плагина>/skills/reel-notes/scripts/server.py --root <папка проекта>
```

Страница — `http://127.0.0.1:8765`. Сервер слушает только этот компьютер и отвечает только своей странице: запросы
с чужим адресом или источником и не-JSON запросы на изменение отклоняются, так что открытый в браузере сайт не может
ни запустить Claude, ни удалить ролик. Без работы — страница закрыта, а Claude, рендер и проверка не
идут — сервер выключается сам через 30 минут (меняется в окне «Настройки», 0 — не выключать).
